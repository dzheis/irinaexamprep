# Настройка Supabase для авторизации и доступа к видео

## 1. Создать проект в Supabase

1. Зайти на [supabase.com](https://supabase.com), создать проект.
2. В **Settings → API** скопировать:
   - **Project URL** → `NEXT_PUBLIC_SUPABASE_URL`
   - **anon public** → `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - **service_role** → `SUPABASE_SERVICE_ROLE_KEY` (только для сервера, не светить на клиенте)

## 2. Переменные окружения (.env.local)

```env
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...
SUPABASE_SERVICE_ROLE_KEY=eyJ...
```

**Админ (доступ ко всем видео без покупки):** добавьте в `.env.local`:

```env
ADMIN_EMAIL=ваш-email@example.com
```

Пользователь с этим email должен быть зарегистрирован на сайте (через обычную регистрацию или создан в Supabase Auth). Под этой учёткой при входе будут видны все модули методики без оплаты. Пароль — тот, что задан при регистрации (отдельного «супер-пароля» нет).

## 3. Таблицы в Supabase

В **SQL Editor** выполнить скрипт из файла `supabase/schema.sql` (создаёт `pending_payments` и `purchases`).

## 4. Auth в Supabase

- **Authentication → Providers**: включить **Email**.
- **Authentication → URL Configuration** (важно и для **localhost**, и для **продакшена**):

### Site URL

- Для **боевого сайта** удобно указать: `https://irinaexamprep.com` — ссылки в письмах (подтверждение, сброс пароля) по умолчанию ведут на этот домен.
- Для отладки только на машине можно временно поставить `http://localhost:3000`, но тогда ссылки из писем будут указывать на localhost (удобно не всем). Обычно оставляют продакшен-домен и тестируют вход локально через **Redirect URLs** ниже.

### Redirect URLs (добавить все строки, по одной на строку)

Локальная разработка (Next.js по умолчанию порт **3000**):

- `http://localhost:3000/auth/callback`
- `http://localhost:3000/reset-password`
- `http://127.0.0.1:3000/auth/callback`
- `http://127.0.0.1:3000/reset-password`

Продакшен **https://irinaexamprep.com**:

- `https://irinaexamprep.com/auth/callback`
- `https://irinaexamprep.com/reset-password`

Если используете **www**, добавьте те же пути с `https://www.irinaexamprep.com`, либо настройте редирект с www на без www и оставьте один вариант.

После изменений сохраните настройки в Supabase. Без совпадения URL редирект после входа/по ссылке из письма может завершиться ошибкой «redirect_uri mismatch».

- **Confirm email**: если включено, после регистрации на почту уходит ссылка; по переходу активируется аккаунт.
- **Recovery (сброс пароля)**: ссылка из письма ведёт на `/reset-password`; там пользователь вводит новый пароль дважды.

### Текст письма подтверждения (Confirm signup)

В **Authentication → Email Templates** выберите **Confirm signup**. Можно заменить тему и тело письма на более дружелюбные.

**Subject (тема):**

```
Подтвердите регистрацию на Irina Exam Prep
```

**Body (тело письма)** — в шаблоне обязательно оставьте переменную `{{ .ConfirmationURL }}` (ссылку подставят автоматически):

```
Здравствуйте!

Вы зарегистрировались на сайте Irina Exam Prep — курсы подготовки к экзаменам по английскому языку.

Чтобы активировать аккаунт и получить доступ к материалам, нажмите на ссылку ниже:

{{ .ConfirmationURL }}

Ссылка действительна ограниченное время. Если вы не регистрировались на нашем сайте, просто проигнорируйте это письмо.

До встречи на занятиях!
Ирина Петрова
Irina Exam Prep
```

### Текст письма сброса пароля (Recovery)

В **Authentication → Email Templates** выберите **Recovery** (или **Reset password**). Замените тему и тело на более объёмный и дружелюбный вариант. В теле обязательно оставьте переменную `{{ .ConfirmationURL }}` — по этой ссылке пользователь попадёт на страницу смены пароля.

**Subject (тема):**

```
Восстановление пароля — Irina Exam Prep
```

**Body (тело письма):**

```
Здравствуйте!

Вы запросили сброс пароля для аккаунта на сайте Irina Exam Prep. Мы отправили вам эту ссылку, чтобы вы могли безопасно задать новый пароль и снова войти в личный кабинет.

Нажмите на ссылку ниже, чтобы перейти на страницу создания нового пароля:

{{ .ConfirmationURL }}

Ссылка действует ограниченное время. Если вы не запрашивали сброс пароля, просто проигнорируйте это письмо — ваш текущий пароль останется без изменений, а эта ссылка вскоре станет недействительной.

Если у вас возникли трудности или вы не создавали запрос на сброс пароля, напишите нам — мы с радостью поможем.

Удачи в подготовке к экзаменам!
Ирина Петрова
Irina Exam Prep
```

## 5. Реальные video_id модулей

В `src/lib/methodology-modules.ts` заменить тестовые `videoId` на реальные ID роликов YouTube (unlisted) для каждого модуля.

## 6. Robokassa Result URL

В личном кабинете Robokassa указать **Result URL** (серверный callback после оплаты):  
`https://ваш-домен.com/api/pay/result`  
Иначе запись о покупке в `purchases` не появится.

---

## Цепочка работы

1. Пользователь регистрируется/входит (страницы **Войти**, **Регистрация**).
2. На странице **Методика** нажимает **Купить** → вводит email → переход в Robokassa.
3. После успешной оплаты Robokassa вызывает **Result URL** вашего сайта → в таблицу `purchases` записывается пара (email, module_id).
4. Пользователь возвращается на `/methodology?payment=success` → запрос **Мои покупки** возвращает купленные модули → для них показывается видео через **/api/video-embed?module=N** (редирект на YouTube), для остальных — заглушка «Доступ после оплаты».
